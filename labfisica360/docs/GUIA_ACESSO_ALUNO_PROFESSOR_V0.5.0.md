# Guia de acesso — aluno e professor

## Para explorar sem atividade
Abra a plataforma, escolha **Explorar sem salvar** e entre em qualquer laboratório. Nenhum login é obrigatório.

## Para uma atividade com registro
1. Abra **Sessão**.
2. Informe nome, turma, turno e um PIN local de 4 a 12 números.
3. Use os laboratórios normalmente.
4. Ao finalizar, abra **Sessão** e exporte JSON ou CSV.
5. Entregue o arquivo pelo canal indicado pelo professor.

## O que aparece no relatório
- identificação e turma;
- turno;
- modo Livre ou Guiado;
- mentor escolhido;
- laboratórios acessados;
- quantidade de acessos;
- tempo ativo;
- quantidade e tipo de ações em controles;
- etapas guiadas concluídas;
- datas de abertura e encerramento.

## Limites
O registro é local e pode ser apagado ao limpar os dados do navegador. Para controle centralizado de turmas seria necessário um backend e autenticação institucional, que não fazem parte desta versão GitHub Pages.
