# Física Imersiva 360 — v0.5.0

Versão R9.2 dedicada à **expansão dos Mentores Históricos e das Trilhas Guiadas**, preservando o portal leve, o Modo Livre e o carregamento sob demanda.

## Destaques

- seis mentores: Albert Einstein, Isaac Newton, Michael Faraday, Marie Curie, Nikola Tesla e Galileu Galilei;
- cobertura guiada dos oito laboratórios;
- cinco laboratórios ordenados por mentor;
- 33 roteiros disponíveis;
- 138 etapas guiadas com clique, entrada, seleção e observação;
- 138 de 138 alvos verificados no navegador;
- progresso local, retomada, dicas, voz opcional e exportação;
- nenhuma dependência de mentor no carregamento inicial;
- Modo Livre permanece como padrão;
- textos apresentados como trilhas inspiradas no contexto histórico, sem citações ou falas inventadas.

## Execução

Abra `index.html` por servidor HTTP local ou publique a pasta em GitHub Pages.
